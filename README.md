# FTC Quiz

A simple home page for an FTC team quiz project. Choose Builder or Driver to see what quiz content is planned. The Builder part quiz and Driver rules quiz will be added in later steps.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and does not require a build step.

The Driver quiz is planned to use the official [2026–2027 FIRST Tech Challenge Competition Manual](https://ftc-resources.firstinspires.org/ftc/game/manual).
