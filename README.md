FTC Quiz
========

A small static website for an FTC team. The homepage is `index.html`; choose Driver to open `driver.html` and Builder to open `builder.html`. The Driver quiz logic and question bank are kept in `driver.js` and `driverQuestions.js`; Builder visual questions use `builder.js` and local illustrations in `builder-assets/`.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

The practice question bank focuses on general driver knowledge and safe match preparation. For season-specific BIOBUZZ scoring, game rules, and penalties, always use the current official [2026–2027 FTC Competition Manual](https://ftc-resources.firstinspires.org/ftc/game/manual).
